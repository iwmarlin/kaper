Object context

The date shown on the file page, January 2013, is that of the scan and not of the sitting; the photograph is placed in the nineteen-thirties by the contributor’s description alone. The studio named as author could not be traced further, and no print, publication or agency mark is recorded. The likeness is therefore dated by decade, and the reliability of the file page is rated accordingly.
