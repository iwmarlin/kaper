Object context

The museum records neither photographer nor date, only the support and the size of the print. The name written across the image, “Monteux Jacques Jacob”, supplies the given names that the authority headings omit. The sitter appears to be in his twenties, which agrees with the application for membership of March 1926 preserved in the same file.
